# NousHub

> **Where thought becomes code.**
> 让思考成为代码，让代码创造价值。

**Nous**（νοῦς）源自希腊语，意为 **心智、理性与思考**。

NousHub 是一个专注于软件开发与开源实践的技术组织。

我们相信，真正优秀的软件并不始于代码，而始于对问题的理解、对结构的思考，以及对长期价值的判断。

代码只是最终的表达方式。

## 🚀 What We Care About

我们更关注软件是否：

* **简单** —— 避免不必要的复杂度
* **清晰** —— 代码和架构应该容易理解
* **可靠** —— 软件应该稳定地完成它的工作
* **可维护** —— 今天写下的代码，也应该方便未来继续维护
* **有价值** —— 不为了技术而技术，不为了代码而代码

---

## 🧠 Our Philosophy

软件开发，本质上是一种解决问题的过程。

在 NousHub，我们更愿意先理解问题，再决定如何实现。

> **Think clearly.
> Build simply.
> Ship thoughtfully.**

我们不追求无意义的复杂架构，也不堆砌没有必要的功能。

每一个模块、每一个接口、每一行代码，都应该有它存在的理由。
